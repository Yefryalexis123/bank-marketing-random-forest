# Bank Marketing Random Forest

Proyecto de Inteligencia Artificial I.

## Objetivo

Predecir si un cliente aceptará una oferta de depósito a plazo utilizando Random Forest y datos reales del Bank Marketing Dataset.

## Dataset

UCI Machine Learning Repository - Bank Marketing Dataset

## Algoritmo

Random Forest Classifier

## Tecnologías

- Python
- Scikit-Learn
- Pandas
- Streamlit
- Joblib
